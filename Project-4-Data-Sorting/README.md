# Project 04 - Data Sorting and Filtering in Microsoft Excel

## Project Overview

This project demonstrates how to organize and analyze employee data using Excel's Sorting and Filtering features.

## Objectives

- Sort employee records alphabetically.
- Sort salary values in ascending and descending order.
- Filter records based on department, gender, designation, and other fields.
- Understand how sorting and filtering help analyze datasets efficiently.

## Excel Features Used

- Sort (A to Z)
- Sort (Z to A)
- Custom Sort
- Filter
- Table Formatting

## Dataset

Employee dataset containing:
- Employee ID
- Name
- Gender
- Department
- Designation
- Salary
- HRA
- DA
- Bonus
- Gross Salary
- PF
- Tax
- Net Salary

## Learning Outcome

After completing this project, I learned how to:

- Organize large datasets
- Quickly locate required information
- Analyze employee records efficiently
- Prepare data for further analysis
