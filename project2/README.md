# Project 02 - Excel IF Functions

## Overview
This project demonstrates the practical use of logical functions in Microsoft Excel.

## Topics Covered
- IF Function
- Nested IF
- IFS Function

## Project 1 - Employee Promotion
Used IF, AND, and OR functions to determine employee promotion eligibility.

### Skills Used
- IF()
- AND()
- OR()

---

## Project 2 - Student Grade Analysis
Calculated pass/fail status and assigned grades using Nested IF.

### Skills Used
- IF()
- Nested IF
- Percentage Calculation

---

## Project 3 - Customer Discount System
Calculated customer discount percentages using the IFS function based on order quantity.

### Skills Used
- IFS()
- Logical Conditions
