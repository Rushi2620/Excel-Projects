# Project 03 - Conditional Formatting in Microsoft Excel

## Project Overview

This project demonstrates the use of Conditional Formatting in Microsoft Excel to improve data visualization and identify important information automatically.

## Topics Covered

### 1. Highlight Cells Rules
- Highlight duplicate values
- Highlight cells based on conditions

### 2. Data Bars
- Display values using in-cell bars

### 3. Color Scales
- Visualize low and high values using colors

### 4. Date Formatting
- Highlight dates automatically

### 5. Pass/Fail Formatting
- Highlight student results using conditional formatting
