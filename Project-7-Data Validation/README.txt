# 📋 Excel Data Validation Project

## 📌 Project Overview

This project demonstrates the use of Microsoft Excel Data Validation to improve data accuracy and reduce input errors.

The project uses an Employee Dataset and applies different types of validation rules to ensure users enter correct information.

---

## 🎯 Objectives

The objectives of this project are:

- Restrict invalid data entry.
- Create dropdown lists for predefined values.
- Display helpful input messages.
- Show custom error alerts for invalid data.
- Improve data quality using Excel Data Validation.

---

## 🛠 Features Implemented

### 1. Dropdown List Validation

Created a dropdown list for the **Gender** column.

Available options:

- Male
- Female

Users can only select values from the dropdown list.

---

### 2. Contact Number Validation

Applied Text Length validation.

Rule:

- Contact Number must contain exactly **10 digits**.

This prevents users from entering invalid phone numbers.

---

### 3. Input Message

When a user selects the Contact Number cell, Excel displays the message:

**Title**

Enter Contact Number

**Message**

Enter a 10 digit contact number.

This helps users understand what data should be entered.

---

### 4. Error Alert

If the user enters an invalid contact number, Excel displays an error message.

**Title**

Error

**Message**

Enter a 10 digit number.

This prevents incorrect data from being saved.
