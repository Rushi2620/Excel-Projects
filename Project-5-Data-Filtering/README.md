# Project 05 - Data Filtering in Microsoft Excel

## Project Overview

This project demonstrates how to use Microsoft Excel's Filter feature to analyze employee data efficiently.

## Objectives

- Filter employee records based on department.
- Filter employee records based on designation.
- Create separate filtered sheets for different designations.
- Practice working with a real-world employee dataset.

## Excel Features Used

- Filter
- Multiple Filters
- Table Formatting
- Data Organization
- Sheet Management

## Dataset

Employee dataset containing:

- Employee ID
- First Name
- Last Name
- Gender
- Department
- Designation
- Base Salary
- HRA
- DA
- Bonus
- Gross Salary
- PF
- Tax
- Net Salary

## Learning Outcome

After completing this project, I learned how to:

- Filter large datasets efficiently.
- Analyze employee records based on different conditions.
- Organize data into separate worksheets.
- Prepare data for reporting and analysis.
