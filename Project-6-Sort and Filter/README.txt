# 📊 Excel Sort and Filter Project

## 📌 Project Overview

This project demonstrates the use of Microsoft Excel's **Sort** and **Filter** features to organize, search, and analyze employee data efficiently.

The dataset contains employee information such as:
- Employee ID
- First Name
- Last Name
- Gender
- Department
- Designation
- Base Salary
- HRA
- DA
- Bonus
- Gross Salary
- PF
- Tax
- Net Salary

---

## 🎯 Objectives

The main objectives of this project are:

- Learn how to sort data in ascending and descending order.
- Apply filters to display specific records.
- Organize employee information efficiently.
- Improve Excel data analysis skills.
- Practice working with large datasets.

---

## 🛠️ Excel Features Used

- Sort (A to Z)
- Sort (Z to A)
- Custom Sort
- Filter
- Search within Filter
- Multi-column Sorting

---

## 📋 Tasks Performed

### ✔ Sort Employee Records
- Sorted employee names alphabetically.
- Sorted employee IDs.
- Sorted salary values from highest to lowest.

### ✔ Filter Employee Data
- Filtered employees by Gender.
- Filtered employees by Department.
- Filtered employees by Designation.

### ✔ Data Organization
- Organized employee records for easier analysis.
- Displayed only required information using filters.
